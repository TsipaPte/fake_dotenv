# Фальшивый .env

## О проекте

Данный проект представляет собой утилиту, которая позволяет сгенерировать файл .env с фальшивыми, но правдоподобными данными. Этот файл можно разместить на сайте, в инфраструктуре или в других местах, где требуется запутать потенциального злоумышленника

## Возможности проекта

Мой проект поддерживает ряд возможностей, чтобы генерировать фальшивые .env было удобнее и функциональнее:

1. **Только те секреты, которые реально нужны**: Вы можете выбрать только те секретны, которые реально нужно сгенерировать под Ваш проект, а не выбирать все
2. **Фальшивый комментарий**: Вы можете задать первую строчку .env в виде фальшивого комментария, который будет гласить о секретности и важности данного .env
3. **Изменение регистра комментария**: Если Вы выбрали добавить фальшивый комментарий, то Вы также можете и изменить его регистр, если он Вам не понравился (или оставить регистр без изменений)
4. **100% локально**: не требуется подключение к Интернету, всё хранится и выполняется только локально, на вашем компьютере

## Установка

Ниже предоставлена инструкция по установке данного проекта на разные операционные системы:

### Windows

Просто перейдите в [релизы](https://github.com/TsipaPte/fake_dotenv/releases) и скачайте готовый `.exe`

### Linux / macOS

Откройте терминал и выполните следующие команды (в папке с проектом):

**Важно:** эти команды выполняются только один раз, при первой установки проекта

```sh
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## Использование (после установки)

После того, как Вы выполнили шаги из блока "Установка" теперь можно запустить наш проект. Обратите внимание, что данные команды (в отличии от установки) **выполняются каждый раз при запуске проекта**:

### Windows

Запустите скачанный `.exe`

### Linux / macOS

Откройте терминал и выполните следующие команды (в папке с проектом):

```sh
source venv/bin/activate
cd src
python3 main.py
```
